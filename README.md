# rag-chatbot-2026-2
Aplicação de Chatbot Web com RAG orquestrado via LangGraph e back-end em Python. Responde a dúvidas em linguagem natural consultando uma base de conhecimento própria e volumosa de um domínio específico. O fluxo realiza ingestão de dados, busca vetorial por similaridade e geração da resposta final por uma LLM externa integrando contexto e histórico.
